# SkillX Task Builder v1.4 – GitHub Pages telepítés

1. Csomagold ki a `SkillX_Task_Builder_v1.4.zip` fájlt.
2. A `skillx-builder-v1.4` mappa **tartalmát** töltsd fel a GitHub repository gyökerébe. Az `index.html` közvetlenül a repository gyökerében legyen.
3. GitHub: **Settings → Pages**.
4. Build and deployment: **Deploy from a branch**.
5. Branch: **main**, folder: **/(root)**.
6. Save.

A ZIP-kezeléshez szükséges JSZip helyben van a projektben, ezért külön backend nem szükséges.
