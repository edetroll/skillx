# SkillX Task Builder v1.2 – GitHub Pages telepítés

1. Csomagold ki a `SkillX_Task_Builder_v1.2.zip` fájlt.
2. Hozz létre egy GitHub repository-t, például `skillx-task-builder` néven.
3. A `skillx-builder-v1.2` mappa **tartalmát** töltsd fel a repository gyökerébe. Az `index.html` közvetlenül a gyökérben legyen.
4. GitHubon nyisd meg: **Settings → Pages**.
5. A **Build and deployment** résznél válaszd a **Deploy from a branch** lehetőséget.
6. Branch: `main`, folder: `/(root)`, majd **Save**.
7. A GitHub néhány pillanat múlva megadja az oldal címét.

## Frissítés
Ha új verzió készül, a repository fájljait egyszerűen cseréld le az új verzió fájljaira. A már exportált `.skillx.zip` csomagok a Builderből újra megnyithatók és szerkeszthetők.

## Megjegyzés
A ZIP import/export teljesen böngészőoldali; nem kell Google API, saját szerver vagy AI API-kulcs.
